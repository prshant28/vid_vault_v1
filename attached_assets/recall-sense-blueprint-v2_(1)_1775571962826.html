Risk Assessment

Risk Radar

Six critical risks plotted by impact × probability, each with a concrete mitigation strategy.

High
Privacy & Data Capture
Users uncomfortable with passive capture; GDPR/CCPA exposure.
Fix: Local-first option, granular controls, on-device processing, full export/delete.
High
LLM Cost at Scale
AI inference cost can destroy unit economics on free tier.
Fix: Token budgeting per tier, cached summaries, smaller fine-tuned models for classification.
Medium
Browser Extension Approval
Chrome Web Store strict review for broad permission requests.
Fix: Minimal permissions first, incremental upgrades, Firefox/Edge fallback.
Medium
Big Tech Competition
Apple Intelligence, Google NotebookLM, Copilot could absorb this feature set.
Fix: Own the cognitive analytics angle. Build team network effects they won't prioritize.
Medium
Third-Party API Fragility
Notion/YouTube API changes can break integrations overnight.
Fix: Abstraction layer on every integration. Local sync fallback. Monitor API changelogs.
Low
Onboarding Complexity
Too many features → high drop-off before first "aha moment".
Fix: Progressive disclosure, single-step onboarding wizard, "aha" in <5 minutes.
