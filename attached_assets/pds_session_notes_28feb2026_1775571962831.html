Problem 1 — Palindrome Checker

🔤 PROBLEM STATEMENT STRINGFUNCTIONSLICING

Task: Write a Python function that accepts a string as input and returns True if the string is a palindrome, and False otherwise. A palindrome reads the same forwards and backwards (e.g., "racecar", "MADAM", "level").

def is_palindrome(s): # Reverse the string using Python's extended slice syntax # s[::-1] means: start=end, stop=beginning, step=-1 (backwards) return s == s[::-1] # Test the function print(is_palindrome("racecar")) # → True print(is_palindrome("MADAM")) # → True print(is_palindrome("python")) # → False
🔍 Concept: String Slicing — s[start:stop:step]
  • s[0] — first character; s[-1] — last character
  • s[1:4] — characters at index 1, 2, 3
  • s[::-1] — entire string reversed (step = -1)
  • Strings are immutable — slicing creates a new string
  • The == operator compares character by character
✅ Why This Works
  • Reversing a palindrome gives the exact same string
  • s == s[::-1] evaluates to a boolean directly
  • No need for a loop — Python's slice handles it in one line
  • Case-sensitive by default: "Racecar" ≠ "racecar"
  • To ignore case, use: s.lower() == s.lower()[::-1]

Problem 2 — Fibonacci Series Sum (First 30 Terms)

🔢 PROBLEM STATEMENT LOOPARITHMETICANSWER: 2,692,537

Task: Calculate the sum of the first 30 elements of the Fibonacci sequence. The Fibonacci sequence starts: 0, 1, 1, 2, 3, 5, 8, 13, 21 … where each number is the sum of the two preceding ones.

# Fibonacci: F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2) x = 0 # First term y = 1 # Second term total = x + y # Start sum with first two terms for i in range(28): # We already have 2 terms; need 28 more = 30 total new = x + y # Next Fibonacci number total += new # Add to running sum x = y # Shift: x becomes old y y = new # Shift: y becomes the new value print(total) # Output: 2692537
✅ Correct Answer
The sum of the first 30 Fibonacci numbers (F₀ through F₂₉, starting 0, 1, 1, 2, 3 …) is 2,692,537. Note: if you start counting from F₁ = 1, the sum shifts by 1 position — always clarify whether the sequence starts at F(0)=0 or F(1)=1. The key algorithmic insight is the sliding window update: x, y = y, x+y.
💡 The Variable Swap Technique
  • After computing new = x + y, we must update both x and y
  • Order matters: set x = y first, then y = new
  • Python shorthand: x, y = y, x + y does both in one line (right side evaluated first)
  • This is a classic two-pointer / sliding window technique used across many algorithms

Problem 3 — Square Root Without Built-in Functions

√ PROBLEM STATEMENT MATHOPERATORS

Task: Write a function to compute the square root of a number without using any built-in math functions (e.g., no math.sqrt()). Multiple approaches were discussed in session.

APPROACH 1 Exponent Operator Use Python's ** operator with 0.5 — clean one-liner, no import needed
APPROACH 2 Newton's Method Iterative numerical method: guess → refine → converge. Shows algorithmic thinking.
APPROACH 3 Binary Search Search between 0 and n for x where x² ≈ n. Logarithmic convergence.
# Approach 1: Exponent operator (simplest — shown in session) def square_root(a): return a ** 0.5 # a^(1/2) = square root of a # Approach 2: Newton-Raphson iteration (from-scratch logic) def sqrt_newton(n, tolerance=1e-9): guess = n / 2.0 # Initial guess while abs(guess * guess - n) > tolerance: # Until accurate enough guess = (guess + n / guess) / 2 # Newton's formula return guess print(square_root(25)) # 5.0 print(sqrt_newton(25)) # 5.0

The ** operator in Python handles fractional exponents. Since √n = n^(½), writing n ** 0.5 is mathematically exact and does not use any imported library — making it fully valid for "no built-in function" constraints.

Problem 4 — Alphabet Position Sum (e.g., "IITJODHPUR")

🔡 PROBLEM STATEMENT STRINGord()DICT

Task: Given a string of uppercase letters (e.g., "IITJODHPUR"), find the sum of each letter's position in the alphabet. A=1, B=2, C=3 … Z=26. So "IITJODHPUR" → I(9) + I(9) + T(20) + J(10) + O(15) + D(4) + H(8) + P(16) + U(21) + R(18) = 130.

Three different approaches were discussed in session, each demonstrating a different Python technique:

## APPROACH 1: Using ord() — most Pythonic and efficient def position_sum_ord(text): total = 0 for ch in text: total += ord(ch) - ord('A') + 1 # ord('A')=65, so ord('B')-65+1=2 return total ## APPROACH 2: Using a string/list index def position_sum_index(text): alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ" # index 0='A', 1='B', ... total = 0 for ch in text: total += alphabet.index(ch) + 1 # +1 because index() is 0-based return total ## APPROACH 3: Using a dictionary mapping def position_sum_dict(text): letter_map = {chr(65+i): i+1 for i in range(26)} # {'A':1, 'B':2, ...} return sum(letter_map[ch] for ch in text) # All three give the same result: print(position_sum_ord("IITJODHPUR")) # 130
Approach Key Function / Structure How It Gets Position Best For
ord() ord(ch) - ord('A') + 1 ASCII value arithmetic — 'A'=65, so any char minus 64 gives its position Recommended Clean, fast, no extra data
String index alphabet.index(ch) + 1 Finds character's position in the alphabet string; +1 to convert 0-based to 1-based Beginner Friendly Intuitive
Dictionary letter_map[ch] Pre-built key–value store; O(1) lookup per character; built via dict comprehension Scalable Easy to extend

Problem 5 — List Manipulation with Even/Odd Condition

📋 PROBLEM STATEMENT LISTMODULOIF/ELSE

Task: Given a list of integers, iterate through it. If a number is even, add 7 to it. If it is odd, add 13 to it. Print or return the resulting modified list.

# Original list (example) numbers = [1, 4, 7, 10, 3, 8, 15] ## Method 1: Modify in-place using index for i in range(len(numbers)): if numbers[i] % 2 == 0: # Even: remainder when divided by 2 is 0 numbers[i] += 7 else: # Odd: remainder is 1 numbers[i] += 13 print(numbers) # Output: [14, 11, 20, 17, 16, 15, 28] ## Method 2: Build a new list (cleaner — preserves original) result = [(n + 7) if n % 2 == 0 else (n + 13) for n in numbers] print(result)
🧮 Modulo Operator (%)
  • n % 2 gives the remainder when n is divided by 2
  • Even numbers: remainder is always 0
  • Odd numbers: remainder is always 1
  • General pattern: if n % 2 == 0: → even
  • Also useful for: divisibility checks, cycling through ranges
⚡ List Comprehension (Method 2)
  • A concise way to create a new list in one line
  • Syntax: [expression for item in list]
  • Can include conditions: [x if cond else y for x in list]
  • Faster than a manual for-loop for building new lists
  • Does not mutate the original list — preserves original data
